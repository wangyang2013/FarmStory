牧场物语风格单机游戏 · 全系统开发与视觉表现终极规范（色彩极尽与丰富细节版）
================================================================================

【全局底层渲染与美术基准（适用于所有模块）】
1. 视角与缩放：绝对禁止“斜45°”或“等轴测”词汇。统一使用【3/4 Top-Down（四分之三俯视）】。角色 16×32（1格宽2格高），脚底中心为 Y-sort 锚点。基础分辨率【480×270】，窗口输出【1920×1080】整数4倍缩放。全局贴图 Filter 必须设为 Nearest。
2. 阴影与遮挡法则：光源固定右上方。阴影偏移基准【左移1px，下移2px】，使用【40%不透明度的深紫/深蓝】。建筑必须有 FadeWhenBehind 效果（玩家在建筑后方时 Tween 降至 0.5 透明度）。
3. 有机感与生活痕迹：地形、水体严禁直线与直角，必须有锯齿状毛边与碎石过渡。建筑必须包含至少两种材质混合，并带有青苔、修补、熏黑等生活痕迹。

================================================================================
【色彩总纲：极尽丰富的田园美学】
================================================================================
一、 色彩比例与层级（60-30-10法则）
--------------------------------------------------------------------------------
1. 60% 基础色（环境底色）：低饱和、暖色调的自然色（如灰绿、米黄、泥土褐）。
2. 30% 辅助色（结构与结构）：比基础色略深或略冷，用于塑造体积感（如深绿、冷灰蓝、深棕）。建筑墙体、树冠暗部均属于此类。
3. 10% 强调色（视觉焦点）：高饱和、高明度的点缀色。如：成熟果实的鲜红、成熟的橙黄、野花的亮粉、水面的反光。用于引导玩家视线，突出可交互物。
4. 严禁大面积使用高饱和刺眼颜色（如纯正的亮绿、亮蓝），所有鲜艳颜色必须“压得住”。

二、 色相偏移（Hue Shifting）进阶技巧
--------------------------------------------------------------------------------
1. 阴影色相：物体的阴影不只是加深，必须向【冷色】偏移。绿色植物的阴影偏向青色或深蓝；红色屋顶的阴影偏向深紫；黄色麦田的阴影偏向暗橙。
2. 高光色相：高光必须向【暖色】偏移。绿色植物的受光面偏向嫩黄；木头受光面偏向浅米色。
3. 绝对禁区：纯黑（#000000）和纯白（#FFFFFF）。最暗处使用深紫蓝，最亮处使用浅米黄。

三、 环境光反射（Bounce Light）
--------------------------------------------------------------------------------
1. 靠近地面的物体底部，会受到地面的反射光。例如：放在草地上的木桶，底部边缘会有一圈极弱的暗绿色反光。
2. 室内壁炉、炉火旁边的家具，必须有橙色/红色的环境光反射面。

四、 色彩过渡与抖动（Dithering）
--------------------------------------------------------------------------------
1. 大面积颜色的过渡（如天空渐变、草地起伏、水面深浅），绝对禁止使用软件自带的平滑模糊渐变。
2. 必须使用 2~3 档色阶的硬切，并在交界处使用“棋盘格交错（Dithering）”技法，制造像素画独有的颗粒感。

================================================================================
第一卷：角色、NPC 与 动物（色彩与神态）
================================================================================

一、 玩家角色与 NPC
--------------------------------------------------------------------------------
1. 皮肤色彩：拒绝死板的肉色，加入健康/微红/小麦色。阴影部分使用带一点紫色的深肉色。脸颊带微红。
2. 服装色彩：衣服必须有明暗面。褶皱用同色系深色像素点表现，不涂黑。色彩需与环境形成对比（如草地中的蓝衣、雪地里的红衣）。
3. 发型高光：顶部高光必须是头发本色的浅色版，并略微偏暖白，体现发丝的光泽。
4. 饰品多样性：帽子（草帽、贝雷帽）、眼镜、围巾、首饰。颜色可以与主衣形成撞色，如深色衣服配亮黄围巾。
5. 状态反馈色彩：疲劳时脸色变白/变灰；生病时人物整体色调变冷、发灰；受击时高频闪烁偏红白光。
6. NPC区分：每个 NPC 颜色搭配必须独立且符合性格（如阳光渔夫穿亮黄防水衣，铁匠穿暗红围裙）。

二、 动物色彩
--------------------------------------------------------------------------------
1. 毛发质感：动物毛发边缘使用色块表现，不使用平滑曲线。受光面毛色偏亮暖，背光面偏冷暗。
2. 稀有毛色：除了常规的黑白、棕黄，增加金色（黄金鸡）、深紫色（幻影牛）、银蓝色等。稀有动物带有专属的柔光粒子。
3. 情绪表现：好感提升冒出粉色爱心；讨厌礼物冒出灰紫色怒气气泡；生病时动物全身变灰，头顶蓝色病气泡。

================================================================================
第二卷：植物与地形（自然色彩的生命力）
================================================================================

一、 植物色彩与光影
--------------------------------------------------------------------------------
1. 树木：树冠分为 2~3 层色阶。受光面用嫩黄绿，过渡色用中绿，背光面用暗蓝绿。树冠边缘参差不齐，透出枝干的暗色。
2. 作物阶段：幼苗（鲜嫩黄绿） -> 长叶（中绿） -> 成熟（果实颜色鲜明，如红/橙/紫） -> 枯萎（黄褐、下垂、变暗）。
3. 风吹 Shader（核心）：必须使用 sin(TIME + random_seed) 保证每株植物【随机相位】，严禁全屏同步。
4. 野花与草丛：草丛比主草地暗一阶。野花用于点缀，可用亮红、亮黄、纯白，打破大面积绿色的单调。

二、 水体与地形（极度丰富的边缘）
--------------------------------------------------------------------------------
1. 水岸线：禁止画直线！必须用“草地-湿泥-浅水（半透明）-深水”至少 4 层 Tile 拼合。边缘呈锯齿状。
2. 水体色彩：水面必须有 2~3 帧波纹动画。靠近岸边浅水区透出沙石底色，水中央呈现深蓝或蓝绿色。水面波光使用浅青色/白色像素点。
3. 道路与泥地：泥土路边缘要碎石溢出。石板路长有青苔（石缝中的暗绿）。

================================================================================
第三卷：建筑外观与室内（材质与空间）
================================================================================

一、 建筑尺寸与材质
--------------------------------------------------------------------------------
1. 尺寸（严格对齐）：自宅 6×9，鸡舍 6×3，畜棚 7×4，温室 7×5。
2. 材质混合（色彩碰撞）：石基（冷灰蓝）+ 木墙（暖棕黄）；或砖墙（红棕）+ 瓦顶（深灰紫）。
3. 生活痕迹：屋顶瓦片不全整齐（修补痕迹）；墙角堆木柴（深褐）；台阶有青苔（暗绿）；石墙有风化痕迹（浅灰白）。
4. 分层结构：Shadow -> Base -> Roof -> Door/Windows/Sign -> Decor -> Overlay（屋檐前端）。

二、 室内色彩与光影
--------------------------------------------------------------------------------
1. 极简初始：仅单人床、壁炉、电视、桌椅。无厨房、浴室。
2. 光斑与色温：室内光源偏暖黄。白天的阳光透过窗户，在地板上留下一块明亮的矩形暖色光斑。夜晚台灯/壁炉光源为橙红色。
3. 材质分区：木地板的拼缝、地毯的流苏、瓷砖的冷色调。利用不同材质和颜色划分功能区。
4. 室内动态：壁炉有火星粒子，烟囱有冒烟。家具摆放留有生活痕迹。

================================================================================
第四卷：物品、天气与特殊生态
================================================================================

一、 物品与矿石
--------------------------------------------------------------------------------
1. 物品图标：16x16/32x32。统一暗色轮廓。品质用边框（银/金/星光），加小星星角标，不加发光。
2. 矿石色彩：绝不发光。铜矿（橙亮）、铁矿（冷灰）、金矿（亮黄）、铱矿（紫黑）。靠色阶和矿脉纹理表现。
3. 宝石：切面用 2~3 档色阶表现反光，如紫水晶的亮紫、深紫、暗紫交替。
4. 化石：土黄、灰褐、裂纹，带有残缺感。掉在地上的物品上下浮动并带有软阴影。

二、 天气与环境特效
--------------------------------------------------------------------------------
1. 天气色彩：
   - 白天：明亮暖阳，饱和度适中。
   - 黄昏：全图叠加橙紫渐变（利用 CanvasModulate），阴影拉长变暗。
   - 夜晚：全图叠加深蓝暗色滤镜，窗户透出暖黄光（不发光，靠贴图）。
   - 雨天：全局偏灰蓝，地面有雨滴涟漪。
2. 云朵与雾：云朵有半透明云影在地上横移。暴雪时加白色半透明雾层。
3. 风：通过风车、草叶摆动、风中飘动的粒子表现。

第五卷：给 AI 的终极开发提示词（直接复制提问）
================================================================================

我在用 Godot 4（GDScript）开发 2D 牧场像素游戏。请严格按照以下核心美术与逻辑要求，为我生成代码，注释用中文：

【底层渲染与光影系统（最重要）】
1. 项目设置 Viewport 为 480x270，Stretch Mode 为 viewport，Scale Mode 为 integer。全局 Filter 设为 Nearest。
2. 废弃斜45度，采用 3/4 Top-Down 视角。角色 Sprite 为 16x32，脚底中心作为 Y-sort 锚点。
3. 阴影：不要使用大椭圆。使用窄长条 Sprite2D 贴合底边，偏移设为 x=-1, y=2，颜色使用 40% 不透明度的深紫色（偏冷）。
4. 建筑遮挡：建筑挂载 Area2D。玩家进入时，使用 create_tween() 将建筑 modulate.a 降至 0.5（FadeWhenBehind）。
5. 色相偏移与昼夜：白天使用暖色 CanvasModulate；黄昏叠加橙红；夜晚使用深蓝。绝对禁止纯黑阴影，所有暗部需带冷色相（深蓝/紫）。

【环境与动态】
1. 风吹 Shader：为植物编写顶点 Shader，根部锁定，顶部摆动。必须使用 sin(TIME + random_seed) 确保每株植物不同步。
2. 地形与水体：道路和水岸线边缘不能是直线，必须使用不规则的像素毛边和碎石 Tile 过渡。水面需带有 2~3 帧波纹动画。
3. 天气系统：雨滴粒子倾斜随风向，地面生成涟漪并淡出。夜晚的天空有星星粒子。

【室内与初始设定】
1. 初始自宅极简：仅包含床、壁炉、老电视和桌椅。没有厨房和浴室。
2. 进入室内调用 TimeSystem.pause()，室内禁用农具，只允许交互。室内需有暖色光斑。
