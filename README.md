# 牧场物语风格单机游戏（Godot 4）

基于 `牧场物语游戏设计文档..md`、`美术风格参考文档.md`、`整改规范.md`、`游戏时间对照表.md`、
`动画效果清单.md`、`个人单机开发要求.md`、`音乐BGM要求.md`、`室内系统设计.md`、`建筑外观设计.md`、
`代码架构规范与系统完整流程.md`、`核心系统设计合集.md`、`扩展系统设计合集.md`、
`角色NPC动植物物品饰品矿石化石天气设计要求.md`、`全局地图系统规范.md`、
`修订美术规范要求.txt` 实现的 Godot 4 农场游戏。

- 引擎：Godot **4.7.2**（`D:\software\Godot4\Godot_v4.7.2-stable_win64.exe`）
- 版本：**0.9.0**
- 平台：Windows 单机，纯离线
- 画面：**16px 柔和像素**，暖调低饱和
- 视角：**矩形地块 + 3/4 Top-Down（四分之三俯视）**，不是菱形等轴测
- 内部分辨率：**480×270**（`viewport` 拉伸 + 整数缩放，4x 放大到 1920×1080）
- 像素对齐：`snap_2d_transforms_to_pixel` / `snap_2d_vertices_to_pixel` 已开启
- 操作：**WASD 移动 + 鼠标左键使用工具 + E 互动 + R 骑乘 + C 图鉴 + M 地图**
- 内容：40 种作物 / 30 种动物 / 40 种鱼 / 16 名 NPC / 8 个节日，含博物馆、图鉴、邮箱、地窖、成就、矿洞战斗
- 界面：中文，浅米白面板 / 细浅棕边框 / 小圆角

|---|---|
| `WASD` / 方向键 | 移动 |
| 鼠标左键 | 对附近地块使用手持物品 |

| `C` | 打开图鉴（8 个分类 + 排序） |
| `G` | 给附近村民送当前选中的物品 |

| `R` | 骑乘 / 下坐骑（靠近坐骑按 `E` 也可；畜棚门口按 `R` 选择牛 / 羊驼） |

| `K` | 骑乘中打开坐骑货袋（驴 / 骆驼 / 羊驼 / 自行车 / 三轮车） |
| `U` | 室内升级自宅（1→2：10,000G + 木材×450；2→3：100,000G + 木材×1200） |
| `=` / `-` | 画面放大 / 缩小（0.5～1.5，默认 0.75） |
| `1` - `0` / 滚轮 | 切换手持物品 |
| `F5` / `F9` | 保存 / 读档（3 个槽位，带缩略图） |
| `H` | 操作说明 |
| `Esc` | 关闭窗口 / 关闭弹窗 |

> 物品槽有简洁的悬停提示（名称 + 数量）。

### 自宅与升级

- **开局命名**：创建角色时可自定义主角名称与牧场名称（最多 8 字）；牧场名牌会显示在自宅左侧
- **存档导入 / 导出**：存档面板底部先选择「目标槽」，再导出为独立 JSON（含缩略图）或从 JSON 导入；使用系统文件对话框，导入当前槽会立即读取
- 初始自宅只有床、壁炉、老式电视、桌椅、窗户、盆栽、镜子与储物箱，**没有厨房/浴室**
- 室内按 `U` 升级：1→2 花费 10,000G + 木材×450，解锁厨房、冰箱、浴室；2→3 花费 100,000G + 木材×1200，增加地窖入口
- 电视可看天气预报；浴室每天一次恢复 20% 体力
- **储物箱 / 冰箱完整管理**：左背包、右储物，点击互转；储物箱 30 格，冰箱 30 格（3 级 60 格）
- **地窖**：12 格，只能放加工品；每 7 天提升一档品质（普通→银→金→星光）
- **邮箱**：主屋门前，每日按进度投递 6 封信，可领取金币/种子/矿石
- 房屋等级、储物、地窖、邮箱、泡澡状态均写入存档

## 地图

- 世界地图 **64×48 格（2048×1536）**，按分区布置主屋、商店、博物馆、矿洞、农田、畜牧区、双池塘与环图河流。
- `M` 或左上角「地图 M」打开大地图：米色面板 + 深棕细边框、黑色 0.6 遮罩。
- 按《全局地图系统规范.md》的 `MapUI.tscn` 节点树实现：ScreenMask / MapPanel / MapScroll / MapContent / MapBackground / FogOfWar / IconContainer / InfoPanel。
- 三层结构：底图（草地/道路/沙地/水域/森林）、静态实体（建筑/设施/资源区）、动态标记（玩家/动物/宠物/NPC）。
- 建筑与设施使用 16×16 像素图标（1px 深色描边），玩家是带朝向的红色箭头；InfoPanel 悬停显示名称与说明。
- 大地图打开时暂停 SceneTree，`M` / `Esc` 由 Always 模式 UI 处理，暂停状态下仍可关闭。
- 滚轮缩放（1.0–3.0 倍）+ 左键拖拽平移；点击建筑/设施图标会自动寻路并关闭地图（A*，目标在墙内时找最近可行走格）。
- **室内 / 矿洞寻路**：自宅按 12×9 房间网格、矿洞按 40×30 网格（避开岩壁与矿石），区域图标也可点击前往。
- 迷雾：玩家移动时按低分辨率遮罩解锁，未探索区域的底图与图标/标签隐藏；**迷雾会写入存档**。
- 多区域：农场 / 自宅 / 矿洞地图自动切换，标题、底图、设施图标与玩家位置均按当前区域绘制。
- HUD 右上角使用 **44×44 指南针**（`Compass.gd`）显示朝向；原常驻小地图已移除。
- 输入动作 `open_map` 绑定 `M`；玩家节点在 `player` 组，地图实体在 `map_entities` 组。

## 当前玩法

### 种地

1. 用 **锄头** 翻地（2 体力）
2. 选中 **种子** 播种（1 体力），只能种当季作物
3. 用 **浇水壶** 浇水（1 体力）；雨天自动浇水
4. 走到房屋门口按 `E` 睡觉，进入第二天并自动存档
5. 作物只在浇过水的夜里生长；成熟后点击收获（1 体力）
6. 到 **出货箱** 或 **杂货铺** 卖钱，再买种子

作物有 5% 概率收获为稀有（施肥后 12%）：超大 / 超重 / 超大超重，
售价 ×1.5 / ×1.2 / 叠乘。稀有个体单独占格并带 ✨。

### 牧场

- 在杂货铺「牧场」页买鸡 / 牛（价格来自 `animals.json`）
- 买饲料，到鸡舍 / 畜棚旁的**食槽**按 `E` 喂食
- 第二天产出蛋 / 奶，动物头顶出现产物气泡，靠近按 `E` 收取
- 抚摸 +5 好感，不喂食掉好感；同栏舍两只好感 ≥50 的同种动物可繁殖
- **幼崽出生判定稀有毛色**（4% / 10% / 22%），终身固定
- 每栏上限 4 只（`gameplay.json`）

### 宠物（多类别 / 多品种）

- 杂货铺「宠物」页按类别筛选品种：狗、猫、鸟、小熊猫、鱼、乌龟、兔子、仓鼠、豚鼠、幼年畜牧、爬宠、昆虫、特殊、水生扩展等
- 每只宠物都有独立栖息地（狗屋 / 猫窝 / 鸟笼 / 鱼缸 / 龟池 / 兔笼 / 仓鼠笼 / 围栏 / 鸟舍 / 水獭池 / 龙窝等），有容量上限；没有空位时会自动扩建并收取栖息地费用
- 宠物有 **好感 / 饥饿 / 心情 / 清洁度 / 健康** 五维状态；感染疾病后头顶显示病气泡，可用宠物药或 200G 治疗
- 靠近宠物按 `E` 打开宠物面板，或按 `P` 查看全部宠物：喂食 / 抚摸 / 玩耍 / 清理 / 改名 / 找回
- **自定义名称**：领养成功后弹出命名框（最多 8 字），之后可在宠物面板改名一次
- **幼年畜牧**：领养后在围栏 / 鸭鹅水池成长，散步可加速；不占宠物上限、占畜棚/鸡舍容量，长大后转为坐骑或成年畜牧动物并继承名字与好感
- **栖息地升级 / 搬迁**：宠物面板可花钱升级栖息地（每级 +1 容量）；「搬迁」后点击草地放置，Esc 取消，放置前显示绿/红网格预览
- **栖息地装饰**：玩具球 / 秋千 / 小镜子 / 水草 / 晒背灯 / 咬木 / 干草窝，每个栖息地最多 3 件，装饰会直接绘制在房屋上
- **专属行为**：高好感猫在自宅床边睡觉；鸟 / 兔 / 龟等可放出（鸟停肩、龟在附近慢爬，超时自动回巢）；晴天乌龟晒背；昆虫每天可斗虫赢取金币；狗高好感会赶跑灌木里的小动物
- 喂食 / 玩耍 / 清理带有低头进食、爱心跳跃与闪光粒子，并播放对应音效
- **品种外观**：犬猫的卷尾/长尾/短尾、垂耳/立耳、长毛/面具/花纹，鸟的冠羽/腮红，鱼的锦鲤斑/霓虹条纹/圆盘体型，龟的高背/红耳/壳纹，兔的垂耳/长毛/狮头鬃毛均由品种配置驱动
- **专属动画**：鸟笼有秋千时站在秋千上摇摆；水质差时鱼躲到水草后只露出尾鳍；玩家靠近时乌龟/爬宠缩壳；猫蜷缩睡觉
- **野生动物**：农场会自然刷新野生小动物；高好感狗靠近会将其赶跑，玩家靠得太近也会逃走
- 喂食消耗对应物种的食物（狗粮 / 猫粮 / 鸟食 / 鱼食 / 兔粮 / 干草 / 坚果 / 肉干 / 昆虫饲料等，可在宠物页购买）
- 狗、猫、兔子、豚鼠、幼年畜牧等陆生宠物会在好感 ≥50 后跟随；鸟、鱼、龟等固定在栖息地内活动
- 领养时独立 roll 稀有毛色；狗/猫高好感每天带回礼物；低好感且饥饿会离家出走，3 天内可在宠物面板找回
- 宠物解锁「宠物」「宠物异色」图鉴分类；宠物上限随栖息地扩建提升到 12

### 果树

- 杂货铺「果树」页买树苗（12 种），选中后点草地种下
- 占用 **3×3** 空间，不能和农田/建筑重叠
- 前几年是幼树，到 `mature_year`（3–6 年）成年
- 成年后在固定季节结果，每季一次；5% 概率出稀有大果（×1.5）
- 点树摘果；用锄头对着树可以砍倒

### 养蜂

- 杂货铺「养蜂」页买 **蜂箱 / 蜂王 / 糖水 / 蜂群药物**
- 选中蜂箱点草地放下，靠近按 `E` 放入蜂王
- 每 **3 天**可收一次蜜；雨天、冬季户外停产（温室可产）
- 周围 **5×5** 内每种开花植物 +5% 效率（最多 8 种）
- 健康 ≥80 有概率额外获得蜂蜡；健康 <20 有 10% 概率逃群
- 每季 5% 概率病害，用蜂群药物治疗
- 稀有蜂蜜（森林蜜 / 百花蜜 / 结晶蜜）可解锁图鉴

### 矿洞

- 农场右上角的岩石按 `E` 进入矿洞
- **100 层**，每层 40×30，石头 30–60 块
- 用「当天种子 + 层号」生成，同一天同一层可复现
- 点击石头敲矿（消耗 4 体力），掉落矿石/宝石，越深越好
- 楼梯距入口至少 10 格，靠近按 `E` 下一层
- **矿洞内时间静止，体力照常消耗**
- 回到入口按 `E` 离开

### 矿洞战斗与陷阱

- 初始自带**剑**（快捷栏选中）；矿洞内点击 / 空格向面朝方向挥砍，伤害 10、冷却 0.5s
- 玩家 HP 100、受击后 1 秒无敌帧；右下角显示 HP 与体力双条
- 4 种怪物：史莱姆 / 蝙蝠 / 鼹鼠 / 深层怪，血量与攻击随层数增强；会巡逻、追击、近身攻击
- 怪物掉落史莱姆凝胶、蝙蝠翅膀、矿石等；击杀后按独立 RNG 判定
- 每层 2–5 个陷阱：暗坑扣 10 HP，滑坡额外扣 5 体力；避开入口/楼梯/石头
- 菜单打开时怪物与陷阱暂停；HP 归零后送矿洞入口，次日 08:00 醒来，体力 50%，无物品惩罚

### 烹饪

- 进自宅后走到灶台按 `E` 打开厨房
- 38 条菜谱，按背包食材自动筛选「能做」的菜
- 支持精确食材和标签食材（任意鱼 / 任意肉 / 任意蔬菜 / 任意水果）
- **成品品质 = 食材平均品质**，影响售价
- 加工类菜谱（奶酪 / 布料 / 葡萄酒等）倍率不超过 5 倍

### 加工机器

- 在杂货铺「加工」页签购买机器（奶酪机 / 纺织机 / 腌菜桶 / 酿酒桶 / 加工台）
- 选中机器后点击空地放置（1×1，参与 Y-sort 与碰撞，会显示在大地图/小地图）
- 靠近按 `E` 打开机器：放入原料 → 按游戏时间加工 → 完成后取出
- 5 种机器 / 7 种加工品：奶酪、黄油、布料、腌菜、葡萄酒、啤酒、瓶装蜂蜜
- 计时使用绝对游戏分钟，可跨天；机器状态写入存档
- 注：`recipes.json` 里保留的早期同名加工菜谱后续可收敛到机器

### 村民 / 好感 / 节日

- 16 名固定 NPC：6 名可结婚候选 + 10 名村民；各有固定外观、生日、喜好与身份
- 每天 9:00–21:00 在村口广场活动；雨天/深夜回避；生日当天全天可见；节日 9:00–18:00 聚集
- 靠近按 `E` 聊天（每天 +1 好感），`G` 送出当前选中物品（喜好 +8 / 讨厌 -5 / 普通 +3，生日 ×3，每天限一次）
- 好感等级：陌生 / 朋友 / 好友 / 挚友 / 可求婚；好感写入存档，提升时头顶冒爱心
- 8 个节日：花祭、料理大赛、海之日、斗牛节、丰收祭、赏月会、冬至、新年
- 4 个评分赛（花 / 料理 / 动物 / 丰收）按规范公式评分与名次发奖；其余为参与庆典；每个节日每年一次
- 节日当天杂货铺休息；节日会场在村口广场（9:00–18:00），面向镜头下方的 NPC 站位为 MVP 日程

> 日程目前是“时段出现在固定站位”，尚未接入 NavigationAgent2D 的逐点移动。

### 钓鱼

池塘边按 `F`：按住左键 / 空格收线，鱼挣扎时松手缓线。
进度满成功，张力满断线。成功后才判稀有（异色 5% / 超大 4% / 超重 6%，可叠加）。

收获 / 钓获 / 动物产物除了「稀有」，还会独立判定**品质**：

| 品质 | 倍率 | 说明 |
|---|---|---|
| 普通 | ×1.0 | 大多数情况 |
| 银 | ×1.25 | |
| 金 | ×1.5 | |
| 星光 | ×2.0 | 少数 |

概率表在 `config/quality.json`：

- 作物：未施肥 70/20/9/1，施肥 40/30/25/5
- 动物：低好感 70/20/9/1，高好感 50/30/17/3
- 鱼：普通竿 70/20/9/1，高级竿 60/25/13/2

品质和稀有（超大 / 超重 / 异色）是两套独立判定，售价叠乘，
但总倍率被 `config/economy.json` 的 `rare_price_multiplier_cap = 3.0` 限制上限。

## 室内

房子门口按 `E` 进屋（`HouseInterior.gd`）：

- 进入室内 **时间完全停止**，不显示天气粒子
- 室内 **禁用所有工具**，只允许交互
- 床：睡觉 → 次日 6:00 + 自动存档
- 镜子：随时修改角色外观
- 储物箱：预留接口
- 门：离开室内，时间恢复流动

进出室内有 0.3 秒淡入淡出，相机切换到室内范围。

## 时间与天气

规则全部来自 `config/environment.json`（依据 `游戏时间.txt` 最新版）：

- 游戏内 1 分钟 = 现实 0.7 秒
- 一天 = **06:00 → 次日 06:00（24 小时）**
- **1 季 = 30 天**，1 年 = 120 天
- **室内时间完全静止**：房屋 / 鸡舍 / 畜棚 / 商店 / 矿洞 / 温泉
- 时间暂停：背包 / 对话 / 钓鱼小游戏 / 剧情 / 菜单 / 挖矿
- 24:00 后睡觉体力恢复减少；熬夜太晚或体力耗尽会晕倒，次日起床延后
- 天气：晴 / 雨 / 暴雨 / 雪，按季节权重随机；雨天自动浇水；换季自动重绘地面
- **睡眠恢复三档**：18:00–24:00 恢复 100%；24:00–02:00 恢复 70%；02:00–06:00 恢复 40%
- **没有强制晕倒时刻**：只有体力耗尽才晕倒，起床延后到 8:00，恢复 50%，**无任何惩罚**
- **时间流速**：慢 1.0 秒 / 正常 0.7 秒 / 快 0.5 秒（调试面板可切）
- 右上角时钟旁会显示 `⏸`（时间暂停）、`疲劳`（体力 ≤20%）、`熬夜中`（0:00 后）
- 每天 6:00 弹日期横幅，换季弹季节横幅

```gdscript
ConfigDB.get_days_per_season()                     # 30
ConfigDB.get_day_end_minutes()                     # 1800
ConfigDB.should_pause_time_for("fishing_minigame") # true
ConfigDB.is_time_stopped_location("mine")          # true
```

## 稀有机制（RarityUtil.gd）

| 类别 | 触发 | 判定 |
|---|---|---|
| 作物 | 收获瞬间 | giant / heavy / giant_heavy |
| 动物 | 幼崽出生 | 稀有毛色（id + 中文名 + 颜色） |

## 音频

`AudioManager`（Autoload）已按《音乐BGM要求》搭好骨架：

- 总线：`Master / BGM / SFX / UI / Ambient`
- BGM 按场景键名播放（季节 / 夜晚 / 矿洞 / 室内 / 节日），切换 0.8 秒淡入淡出
- 同一首 BGM 不重复从头播放
- 对话时 BGM 自动降低 6 dB（ducking）
- SFX 按名字播放，短时间重复会节流
- 音量设置写入 `user://settings.json`，与存档分开

- 授权与来源见 `assets/CREDITS.md`；游戏内「设置 → 制作人员 / 素材授权」也可查看
- 素材缺失时所有播放接口仍会安全静默
